### 2. [TechPulse — News Aggregator Microservices Platform](https://github.com/priyagupta35/techpulse)
> **Stack:** Java 17, Spring Boot 3, Spring AI (DeepSeek), PostgreSQL, Docker Compose, Render
- Architected a distributed platform decomposed into two decoupled services:
  - **[News Delivery Service](https://github.com/priyagupta35/news-delivery-service):** Exposes secured endpoints with JWT RBAC (Reader, Contributor, Admin) and automated 2–3 sentence summaries via Spring AI.
  - **[News Ingestion Service](https://github.com/priyagupta35/news-ingestion-service):** Automated Spring Scheduler pipeline pulling articles from NewsAPI every 30 minutes with deduplication.
  - **[TechPulse Docker](https://github.com/priyagupta35/techpulse-docker):** Orchestration setup spinning up the complete ecosystem locally.
- 🔗 **[Delivery API Live Endpoint](https://news-delivery-service.onrender.com/api/articles)** · **[Ingestion API Health](https://news-ingestion-service-3.onrender.com/api/ingestion/health)**
